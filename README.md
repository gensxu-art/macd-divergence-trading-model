# MACD 背离合约交易模型

一套加密永续合约的逆势背离交易模型：**背离引擎负责找入场，硬规则过滤器负责拒绝烂信号，两段式入场负责压成本，单张滑动止损负责全部出场**。全流程规则化、可回测，执行由自动化脚本闭环完成，人的裁量被压到最小。

> ⚠️ 本仓库是个人量化研究记录，不构成任何投资建议。文中所有收益数字均为**回测/离线研究口径**（含已知方法学缺陷，见研究日志），不代表实盘结果。背离类策略的公开实证支持本身偏弱——本仓库的研究日志里包含多项对本模型不利的证伪结果，一并公开，供参考与批评。

> **状态更新（2026-11-24）：rev9 背离模型已退役**（回灌对齐证伪＋背离入场家族全域不过线），下文模型速览为历史口径；现行实盘系统为 **1H 结构矩阵＋唐奇安趋势线**，现行参数见 [策略规格顶部「现行口径」一节](docs/strategy-spec.md)，沿革与全部判定见 [研究日志第 9–18 节](docs/research-log.md)。

## 设计哲学

1. **裁量收进硬规则**：能不能进、进多少、何时出，全部由可回测的规则决定，不靠临场感觉。
2. **成本是一等公民**：背离系统在回测里的账面收益，大半会被手续费与滑点吃掉；费比过滤、maker 入场都是为此而设。
3. **每个想法先离线验证再谈上线**：预注册口径、样本外留出集、成本压力测试，过不了就否决——本仓库的「已否决清单」比「已采用清单」长得多，这是刻意的。

## 模型速览

| 组件 | 口径 |
|---|---|
| 信号 | MACD(12,26,9) 价格背离，只认已收盘 K 线，pivot ±3 确认 |
| 评分 | 背离强度分 1–3 单位：MACD 背离 1 + RSI(14) 背离 1 + 成交量背离 1；更高周期同向背离为「共振」 |
| 标的/周期 | BTC / ETH / SOL / DOGE 的 USDT 永续，统一 30m |
| 过滤 | 单仓互斥、弱信号（1 单位非共振）、费比 > 0.5R、现价越 TP1、追价、强平缓冲、宏观事件闸（默认关） |
| 入场 | 两段式：maker 贴盘口等 10 秒，未成交部分在 20 秒总窗口内限价补量（穿价 ≤ 0.25R），超时不追 |
| 出场 | C 线单张全量市价止损：峰值浮盈 < 1R 时滑动距离 1.0R，≥ 1R 后收紧到 0.3R；只向有利方向移，永不宽于初始止损；无独立止盈单 |
| 风险 | 单笔风险 = 权益 × 4% 封顶；评分只决定放行、不放大仓位；同时最多 1 仓 |

## 当前验证状态（如实）

- 30m 主口径经前视修正后的回测仍为正期望，但回测与真实成交之间存在已量化的粒度落差（1 分钟重放约 −0.35R/笔量级），且修正回测绝对收益数字**不得**单独引用。
- 2026-11 的两项后续研究（5 分钟变体、12 个月「背离强度门槛」全量研究）均被留出集证伪：**背离程度与进场后表现之间不存在可用的单调关系**。
- 因此本模型目前定位为**研究中的策略框架**，其独立进场依据的证据强度有限；作者正在并行验证趋势类策略作为替代/组合核心。
